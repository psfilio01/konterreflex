# Prompt 07: Real life replay
Branch: `feature/real-life-replay`

Build the first main case. The user verbally describes a situation that already happened. Extract context, people, relationship, key statement, emotional/social tension and missing information. Ask at most essential voice follow ups, reconstruct the scene with moderator and actor voices, then let the user answer and receive the standard qualitative feedback. Let the user generate a similar practice variation afterwards.

Acceptance: no typing is required; extraction is editable or confirmable; private cases are visible only to their owner. Finish the mandatory Git workflow.
